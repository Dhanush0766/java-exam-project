# My App

This is a simple Maven project.

## Prerequisites

- Java Development Kit (JDK) 8 or later
- Apache Maven

## Compilation

To compile the project, run the following command from the `my-app` directory:

```bash
mvn compile
```

## Running the Application

To run the application, run the following command from the `my-app` directory:

```bash
mvn exec:java -Dexec.mainClass="com.mycompany.app.App"
```

## Running Tests

To run the tests, run the following command from the `my-app` directory:

```bash
mvn test
```
